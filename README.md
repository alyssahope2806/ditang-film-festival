# 城市充電計畫｜帝國製糖廠微電影影展

繁體中文學生網頁期中專案。

## 開啟方式
用 VS Code 開啟此資料夾，再用 Live Server 開啟 `index.html`。

## 專案結構
- `index.html`：主要頁面及 SEO
- `css/style.css`：版型、Grid、RWD
- `js/main.js`：手機選單、圖輯分頁
- `images/photo-placeholder.svg`：照片載入失敗時的備用圖
- `PROMPTS.md`：AI 指令紀錄

## 圖片與授權
照片使用第三方遠端 URL，須連網才能顯示；網站內標註來源。課堂以外的公開展示請確認使用授權或改用自行拍攝的照片。

## 部署
InfinityFree：上傳 index.html、css、js、images 資料夾到 htdocs 根目錄。
Vercel：匯入 GitHub 專案或上傳專案。
GitHub：提交 PROMPTS.md 並複製檔案網址。
